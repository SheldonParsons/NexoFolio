# Observed documents 1.0.0

Internal Bearer authentication and local project access are required on all endpoints. No ZenTao request or token renewal occurs during reads. Lists never embed raw bodies. All data is observed/unclassified, not an adjudicated or business-confirmed contract.

GET /v1/projects/{project_id}/interfaces?environment_id=UUID&page=1&limit=20&query=optional -> InterfacePage. Environment is required; page1..100000, limit1..100. query is a case-insensitive literal substring of method or path, max500 UTF8 bytes, not semantic/full-text search. total is after filtering in that environment. Stable order method,path,id. No fake folder tree; classification is unclassified for every initial document.

GET /v1/projects/{project_id}/interfaces/{interface_id}?environment_id=UUID -> InterfaceDetail. Definition is the current observed baseline in that environment. The same project/method/path shares interface_id across environments, with a separate current revision per environment. origin_ingestion_id points to its original sample. created_at uses UTC RFC3339. A missing project/environment/interface relationship is404; unauthorized is403; missing permission snapshot503; invalid token401.

GET /v1/projects/{project_id}/interfaces/{interface_id}/observations?environment_id=UUID&page=1&limit=20 -> ObservationPage. Processed observation summaries with outcome and difference IDs. No raw payload here. More samples are fetched page by page.

GET /v1/projects/{project_id}/observations/{ingestion_id} -> ObservationDetail. Can be queried immediately after upload accepted to inspect pending/processing/completed/failed. Contains raw_record unredacted and may be up to the accepted single-record size. completed means this processor committed its result; difference_recorded means pending comparison, not approved or applied. proposed_definition is present only for a difference and does not replace current InterfaceDetail.definition. Compare it against the referenced current baseline; automatic adjudication and difference acceptance are absent.

Definition extraction records observed query parameter names/types, header names/types, media types, request/response JSON fields and actual types. Query values are strings. Body absence, capture failure/truncation, invalid JSON, null/empty arrays, non-JSON and extraction limits are explicit; none implies complete business knowledge. No required fields, Chinese meanings, enums or human assertions are inferred. Arrays include all distinct element shapes up to a10000-node/64-depth extraction budget. Raw sample strings, headers and values are not redacted or replaced.

First observation in an environment creates an immutable baseline and current pointer. Later equivalent extracted definitions attach a sample with unchanged outcome. Different extracted definitions create/reuse a pending difference with base revision and proposed definition; they NEVER overwrite the baseline. Future version handling needs a separate adjudication implementation. This worker does not update ingress dedup heads, invoke models, classify or rebuild directories.

Worker claims in received_at/id order per project/environment/interface, preserving order across concurrent workers. Claim lease120s, processing deadline90s, retry2/4/8/16 seconds, fail after5 attempts. A failed item blocks its same-key successors until repaired and explicitly retried; other keys continue. Old generation/expired owners cannot finish or report failure. Result tables and completed state commit atomically. Manual administration: nexofolio-admin process-one; nexofolio-admin retry-observation <ingestion_id> only retries failed items. No frontend retry/delete/adjudicate endpoint is exposed.

Configured worker (ZenTao base set, same as business API mode) polls PostgreSQL every idle second. An unconfigured foundation worker remains idle. Migration005 must run before starting the new worker. No in-memory queue claims to provide persistence; restart recovers outstanding claims when leases expire.

Comparison is directional: known array element schemas cover later empty arrays when all other fields and metadata remain covered. Such queued observations link as unchanged and preserve the baseline; first-empty then populated observations continue to a pending difference as newly observed information. Only EMPTY_ARRAY_ITEM_TYPE_UNKNOWN may be omitted from limitation comparison; truncation, null, extraction limits and other metadata retain conservative handling. Existing recorded differences are not automatically adjudicated or deleted. Wire schemas and extractor_version remain unchanged.

New template-identified observations create method/template identities and path parameters (in=path, neutral param1/param2 names, string URI values). Admission pins the identity; worker does not reinterpret with a newer project policy. Original URL/values remain in raw observations. Legacy documents, definitions and pending queue identities are not rewritten; old receipts are immutable. Different structures within one template remain pending differences, not overwritten definitions.

Classification now reflects the current official directory: classified when the active version assigns a business directory, unclassified otherwise (including its fixed system folder). Definition/revision/evidence remain independent of directory publication.
