# 批量接收、去重与环境验证

状态：后端实现和隔离验收完成，插件由独立任务实现并提供自己的验证结果。

## 已实现

- 项目环境列表、创建、重命名；支持中文名称、稳定 ID 和旧名称别名。
- 首次按环境名称上传自动创建，选择已有环境则按 ID 解析；跨项目/不存在 ID 拒绝。
- 通用批次信封和按类型校验，首轮只支持 HTTP 观测；逐条回执和能力查询。
- 项目/环境ID/服务/接口身份范围内的当前结构去重；普通值变化可忽略，新环境、新结构或不确定观测转交。
- 原始请求头和正文不脱敏。accepted 原子保存到 ingestion_inbox，状态 pending；不实现下游正式建档、裁决、模型或重构。
- 重试按主体＋来源实例＋记录 ID 处理；原回执可回放，改内容重用 ID 明确冲突。
- 持久化比较投影只使用当前 admission，不用所有历史记录作为去重集合；A→B→A 的最后一个 A 仍转交。

## 接收集成用例

- 中文环境自动创建、列表、显式创建同名复用、改名保留 ID、旧名别名与 ID 重试一致。
- 不能使用另一个环境已经占用的旧名称，首尾空白拒绝，无权限项目的环境列表拒绝。
- 原文及业务 Authorization/Cookie 合成值与数据库保存值一致。
- 同记录重发、换批次重发回放原回执；同记录换环境发生冲突。
- 同项目不同环境分别接收；同环境不同 domain 同结构可 ignored。
- 普通 JSON 值变化可 ignored；字段/类型/状态变化不忽略，数组检查所有元素的结构；空数组/null/截断不肯定去重。
- A→B→A 不被历史 A 误拦截，重复旧 record_id 不改变当前投影。
- 混合批次中的未知类型、无效记录逐条拒绝，合法条目继续。
- 并发同记录只产生一个下游项；服务重启后仍可回放持久回执。
- 50 条同结构不同 ID 合成观测产生 1 个下游项、49 个 ignored。
- 缺环境、51 条超限、单条超过 4 MiB、批次超过 8 MiB、压缩请求分别拒绝；未登录/无项目权限不能提交。
- 人为制造数据库写入失败，整批合法条目与自动环境创建均回滚；没有 accepted 假回执。

50 条小体积合成观测的一次本机测量，优化前约85ms、批量读取/回执写入后约31ms。该数据仅是单次实现观察，不是高并发基准、吞吐承诺或正式 SLA。
当前仍对每个新 record_id 保存紧凑回执以保证幂等；没有无成本的无限存储，长期保留策略后续单独确定。
