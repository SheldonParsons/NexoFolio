# 管理中心：已注册用户列表

2026-10-11。仅增加只读列表，不新增注册流程、同步禅道全员或用户修改操作。

## 数据与边界

- 注册口径为首次成功登录 NexoFolio 后写入 `access.users` 的记录，按首次登录时间倒序、用户 ID 倒序稳定分页。
- 姓名、头像复用 `access.profile_preferences`；无头像或图片加载失败时前端使用姓名首字。账号身份保持 `access.users.account`。
- 返回用户 ID、账号、展示名、头像、启用状态、首次登录时间和最近登录时间；不读取或返回会话、凭证、授权列表和个人简介。
- `UserDirectory` 是 access contracts 的只读端口，PostgreSQL adapter 查询自己拥有的数据。无需数据库迁移，不修改用户或登录时间。

## 权限与查询

`GET /v1/user-management/users?page=1&limit=20&q=姓名或账号`。分页参数 `page=1..100000`、`limit=1..100`，关键词不超过 100 字，不接受控制字符；姓名和账号进行不区分大小写的字面子串匹配，`%`、`_` 不作为 SQL 通配符。

HTTP 与现有项目管理共用管理中心身份中间件，先鉴权再解析查询，匿名、普通、过期及停用身份统一返回 404。adapter 在一致事务中重新验证管理身份，并限定当前实例。响应禁止缓存。MCP 和公开文档没有此读取入口。

## 界面与验证

路由 `/management/users` 继承管理中心的权限守卫，左侧增加“用户管理”。页面只提供列表查询、刷新和分页，不提供编辑、停用、删除按钮。复用黑白主题和 Reka 头像组件；手机端将列表改为易读的分组布局。

隔离 PostgreSQL 集成测试覆盖权限、跨实例、分页、姓名覆盖、头像、字面搜索、时间不变及无修改方法；真实浏览器检查使用临时数据库和合成用户，不读取生产数据。此内部功能不进入公开更新日志。
