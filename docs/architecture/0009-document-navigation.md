# 文档导航下一批：目录概览、悬浮预览和独立路由

状态：规划，2026-10-07；用户明确要求先阐述，尚未实施或新建执行会话。三项作为同一批界面交付，使用同一份目录、接口及关系知识。

## 独立路由先确定

保留项目文档入口 `/projects/:projectId/interfaces`，新增：

- 目录：`/projects/:projectId/interfaces/folders/:folderId`。
- 接口：`/projects/:projectId/interfaces/endpoints/:endpointId`。

分享按钮带当前环境 `?env=<环境ID>`。字段/样本 tab 可用明确 query 表示；第一版不分享临时 hover、搜索输入或树的折叠状态。资源用稳定 ID 定位，名称修改和目录移动不改变链接。目录生成也要遵守稳定身份及差异更新。

目录名、接口行和预览里的“打开详情”都使用真正的路由链接，支持浏览器复制地址、Ctrl/Cmd 点击及新标签页。目录的折叠箭头是独立按钮，只折叠，不导航。

URL 是右侧显示和当前选中的依据：直接打开、刷新、前进/后退都恢复同一目录或接口，展开其祖先，显示并定位左侧选中项。环境和 tab 从 URL 恢复；没有环境参数时按项目既定默认选择，目标在此环境无观测时明确提示，不擅自换成别的接口。

登录拦截保留完整目标 URL，登录后直达。链接不授予项目权限，仍需有权用户访问。失效或无权链接明确显示状态；有稳定别名/替代信息时可跳转，没有时不能悄悄打开另一个同名项。

分享给其他人要使用可访问的部署地址；127.0.0.1 是当前电脑。生产服务需要支持 SPA 深链接刷新，不能只验证从首页内点击能打开。

当前 router 会在 path 改变时触发进入过渡及通用滚动处理。实现时须区分同项目目录/接口切换与真正跨项目进入：内部切换复用项目索引，局部载入右侧，保持左侧浏览位置；不要每次出现整页加载或把侧栏滚回顶部。

## 点击后的目录概览

点目录名称在右侧选择目录；点接口显示接口详情。折叠状态与右侧选择分开，hover 也不改变选择。面包屑支持返回目录。

- 紧凑标题：名称、目录路径、当前环境和有效范围内的数量。
- 短介绍：模块做什么、涵盖什么，来自已有目录摘要和成员接口知识。
- 一级目录：子目录及用途/数量、可用场景入口、重要关系摘要。
- 二级目录：接口方法、名称、用途和必要范围，以及输入来源/上下游。
- 关系跨目录呈现，能跳到来源接口；样本对应、候选和已确认前置分清。
- 有资料缺口就显示缺口，目录成员顺序不作为固定调用顺序。

内容点击时读取保存知识及其投影，不现场让模型编摘要，不另建一套手写场景文档。

## hover 是短预览

目录和接口在侧栏、概览列表中采用同一预览交互。复用现有 reka-ui 弹层体系与主题变量，不新增另一套视觉风格。

| 对象 | 卡片内容 |
|---|---|
| 目录 | 名称/层级、1–2 行介绍、子目录及接口数量、打开概览/复制链接 |
| 接口 | 方法+中文名称、目录路径、1–2 行用途、可复制的接口路径、当前环境；已知且有帮助的数量/范围信息；打开详情/复制链接 |

面板只展示轻量摘要，不自动展开字段树、完整样本、原始报文或凭证。有关系信息时可显示少量有依据的摘要，数量本身不作为质量评分。

建议初始视觉：宽约 360–400px，标题清楚、正文较轻、路径用较小等宽字；细边框、浅阴影、适度圆角，复用现有黑白灰和暗色主题。长标题/用途限制展示行数，完整信息在详情中读取。

建议交互参数（待实际视觉验证微调）：

- 停留约 350ms 打开，快速划过不出现。
- 离开触发项后约 180ms 再关闭；进入面板取消关闭计时，支持点击按钮。
- 入场约 160ms，透明度渐入及 4px 小位移；退场约 120ms，渐隐、小位移，不弹跳、不推挤页面。
- 系统减少动态效果时关闭位移等动画。
- 连续扫过多项只显示一个面板，取消旧计时/请求，避免旧内容迟到盖住新项。
- 定位在侧栏右侧，靠边自动避让；在不会被列表 overflow 裁切的容器中渲染。源列表滚动、路由切换或目标消失时关闭。
- 键盘焦点也能获得预览，Escape 关闭，打开/复制链接可通过键盘使用；不抢焦点。触屏以点击进入详情为主。
- 去掉与新预览重叠的浏览器 title tooltip；左侧长标题优先静态省略，完整标题在预览显示，避免滚动文字和弹层同时运动。

已有索引摘要立即复用。缺少轻量信息时才做有界、可取消的摘要读取；缓存按项目、资源、环境区分，新整理版本出现后更新，不为 hover 请求全部样本。

## 实现职责与顺序

1. 独立的文档路由解析/构建和资源选中恢复，保证刷新、登录和历史行为。
2. 独立目录树与目录概览组件，接上两层目录数据和面包屑。
3. 独立共享预览卡组件、计时/定位/轻摘要读取，复用相同路由生成器。
4. 综合验证视觉与导航，不把所有逻辑追加到 ProjectDocumentPage 或 useDocumentWorkspace。

当前首轮关系/MCP 实施会话继续其既定范围，本规划暂不交给它追加 UI 范围。后续执行时，先协调公共合同与已有资料投影，避免同目录生成/首轮知识任务互相覆盖。

## 验收

- 任意目录/接口深链接能直接打开，刷新/新标签页/后退前进都定位正确；带环境能复现当前数据范围。
- 名称修改和移动目录后 ID 链接仍定位到同一资源；失效/权限不足有明确状态。
- 登录后返回原深链接，生产深链接刷新也能加载。
- 目录名、折叠箭头、hover 各执行自己的行为；hover 不替换右侧当前内容。
- 打开/退出顺滑，快速扫动无闪烁/旧数据，进入卡片不消失，滚动和视口边缘没有悬空/裁切。
- 排版在长名称/长路径、暗色、窄窗口和键盘操作下仍可读。
- 所有概览、预览、详情读同一份知识，保持证据与未知事项，不展示敏感凭证。
