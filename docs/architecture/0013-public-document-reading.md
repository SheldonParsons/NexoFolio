# 网页公开只读文档

2026-10-10。按用户确认采用全局规则，不增加项目开关、管理角色或成员关系。当前部署所配置禅道实例中的项目，允许通过原有项目/目录/接口链接阅读文档。

## 访问边界

- 未登录、会话失效、已登录但无项目操作权限：公开只读页面。
- 有有效项目权限：沿用原完整页面、真实样本和现有操作。
- 只读模式支持目录、搜索、环境选择、字段展开、说明和链接分享，不挂载整理、候选、样本、观测值控制器。
- 所有原成员 API、写入 API、MCP 凭证和项目检查保持原逻辑。公开阅读不生成授权关系，不扩大 MCP 范围。

## 服务端

独立只读路由：

- `GET /v1/public/projects/{project_id}/document`：项目名称、状态、环境、正式目录、接口卡片。
- `GET /v1/public/projects/{project_id}/endpoints/{endpoint_id}?environment_id=...`：方法、路径、正式接口说明、字段结构和字段说明。

access 的 `ProjectDocuments` 只读端口限定服务配置中的实例并检查项目存在，不复用成员授权的“允许”状态。HTTP 层通过已有 observe / knowledge 读端口取得资料，以独立白名单 DTO 投影。

不返回请求/响应原文、Header 值、认证载体、观测原值、证据正文、样本标识、来源上下文、输入哈希、作者身份或候选内容。正式说明文字保持原文，会作为公开文档展示；不声称任意人工或模型撰写的说明文字都已经自动脱敏。

未知项目、外部实例、混用项目/接口或环境返回 404。仅解析已建立的接口别名，不按名称替换。公开接口只有 GET/HEAD，响应 no-store；它们不暴露项目枚举入口或写入入口。

## 网页

原文档路由改为可选登录，登录失败不阻止阅读。`ProjectDocumentRoute` 根据有效成员访问检查选择完整页面或独立公开页面，已有授权控制器保持原职责。身份变化时立即移除旧模式；成员请求返回 403 时降为公开模式，401 时清除过期身份并只读查看。

公开页复用目录树、搜索、目录概览、面包屑、链接分享及字段树纯函数。它使用独立公开响应类型，不伪造完整成员响应，也不在隐藏按钮后继续读取受保护的数据。

项目列表中的无操作权限入口也可进入只读页面。操作权限未确认或会话失效时不自动记忆为成员项目；项目确实不存在时保留错误提示。只读访问不写入 MCP 使用的已授权项目上下文。

本次没有新增数据库迁移或改动 MCP 的路由、工具和权限端口。后端发布后前端才可读取新的公开 API；生产发布应先更新后端、再更新前端。
