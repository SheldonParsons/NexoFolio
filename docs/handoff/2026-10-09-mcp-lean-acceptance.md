# MCP 第二轮：减重与分层读取验收

使用 Codex + GPT-6.1 Sol，由用户执行真实模型测试。合成回归里的字符量不代表商用订单管理系统的实测结果。

## 先确认加载的是这一版

工具仍为 11 个。核对实际工具定义：read_interface 支持 field_summary，inspect_knowledge_coverage 支持 summary/issues、issue_kind 和 field_key。仅看到 11 个工具或新版网页说明不能证明后端已更新；加载新版后端后，应刷新 MCP 工具定义。

## 1. 固定字段的内容对照

这一项只比较资料层次，不与上一轮从目录开始的总调用次数直接比较。

~~~text
请只用本轮 NexoFolio MCP 返回的信息，在“商用订单管理系统”的测试环境定位管理端完成技术咨询任务接口，检查请求字段 actTaskHandleDTO.taskId。不要读取历史业务记忆或本地项目文件，不要求我提供 UUID。

先读取完整业务语义、生成状态、确认状态和关联/证据摘要，证据与观测值按需再展开。随后为本次对照单独读一次完整字段资料快照。报告两层实际返回字符量、说明与未知点是否一致、关系确认状态是否一致，以及完整证据与原值能否继续读取。读两份资料只用于对照，不是日常检索建议。不发送业务请求，不整理或应用。
~~~

## 2. 自主检索对照

新任务执行，不预填字段或来源接口 ID。若选择的字段或资料已变化，说明差异，不直接宣称与旧记录是同一基线。

~~~text
请使用 NexoFolio MCP，在“商用订单管理系统”的测试环境自主探索技术咨询相关目录，找一个字段说明提到其他接口或已有相关证据的字段，沿线索找到对应接口并核对样本。定位和事实结论只依据本轮 MCP 返回，不读取历史记忆或本地项目文件。

完整读取必要的业务说明，证据和原文按需展开；已有精确来源引用时可以直接读取，需要比较样本或引用失效时再看索引。只汇报本任务相关的资料缺口，其他未确认字段先作分类统计，不必逐条读完。

任务开始时记录时间。每次实际 MCP 调用（包括循环中的每次续页和失败重试）分别计数，记录工具、范围、返回条数或字符量、分页和耗时；外层脚本次数不等于 MCP 次数。token 只报告客户端实际提供的统计，拿不到写未知。最后报告依据、确认状态、未读范围和统计口径。不发业务请求，不整理或应用。
~~~

检查字段详情是否仍带重复依据、是否重复查询同一关系、覆盖是否先汇总再选择类别或字段、精确来源是否减少不必要的样本枚举。以证据需求判断多读是否合理，不以调用最少作为唯一标准。

## 3. 参数修正和长原文续读

这是机制专项，故意的小块读取与错误调用单独统计，不计入自然检索的效率对比。

~~~text
选择一份实际保留的请求或响应资料，先故意用 max_chars=20000 发起一次只读获取，检查是否指明参数、允许范围和建议值。随后按允许范围修正，用 max_chars=1024 续读到完整，逐次原样使用 next.arguments，核对同一来源版本、连续范围和总字符数，拼完整后再解析 JSON。不猜偏移，不修改源数据；数据不足以触发分块时明确说本场景未覆盖。
~~~

## 4. 纯文字线索

~~~text
另选一个真实字段：文字能提供相关接口或业务功能线索，但没有可直接使用的结构化关联或接口引用。自行提取搜索词、浏览并核对来源，给出本轮证据。没有这种资料就标记“本次数据未覆盖”，不假装没看到已有 ID，不编造接口或关系。不使用历史业务记忆，不发送业务请求。
~~~

## 判定

先核对结论、字段位置、环境与证据完整性，再比较字符量、调用、重试和耗时。字符量不等于 token；语义候选不等于整理失败；替代样本不等于原证据。

## 第三轮导航投影补充

字段树仅 children>0 的节点提供 expand，完整结构路径仍在 field_summary / field。字段搜索通过 matched_field.open 直达语义，不附重复概览入口及流量数据；需要上下文可按已返回的 endpoint_id 读取 overview。工具数量和调用参数不变，测试前刷新实际工具说明。

同查询的直接运行时对照保存在本地 `docs/audits/2026-10-09-mcp-navigation-projection.md`；运行记录默认不提交到仓库。该对照未再次运行模型，不代表默认工具选择已通过无提示测试。

如需另测自然任务，可在新会话仅提供业务目标，不预先指定工具或读取层次：

~~~text
请使用 NexoFolio，在“商用订单管理系统”的测试环境找出完成技术咨询流程任务需要的任务 ID 可以从哪里取得。自行选择检索路线，核对必要证据，说明取值条件和仍不确定的地方。只依据本轮返回，不读取历史记忆或本地业务文件，不发送业务请求、不整理或应用。记录每次实际 MCP 调用、返回量、失败及耗时；token 没有客户端统计就写未知。报告未读范围。
~~~
